Run Locally

The application source code is located in the "my-portfolio/" directory.

git clone https://github.com/Chizitelum0/My-portfolio-.git
cd My-portfolio-/my-portfolio
npm install
npm run dev

Open the local URL printed by Vite in your terminal.

Available Scripts

npm run dev      # Start the development server
npm run build    # Build for production
npm run preview  # Preview the production build
npm run lint     # Run ESLint

Contact Form Configuration

The contact form is integrated with Web3Forms.

Create a ".env.local" file inside "my-portfolio/" and add your access key:

VITE_W3F_KEY=your_web3forms_access_key

Do not commit private credentials or API keys to GitHub.
